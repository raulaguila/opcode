# Protótipos

As duas interfaces novas seguem estes protótipos. Abra os arquivos no navegador.

- [proposta-visual.html](proposta-visual.html): a proposta visual original, com
  as 12 telas (conversa, seletor e detalhes do modelo, comandos, aprovação,
  pergunta, plano, preferências, conexões, conversas, nova conexão e a tela
  compacta). É a referência do app (`opcode app`). Arquivo único, com as fontes
  embutidas.
- [terminal.html](terminal.html): as mesmas 12 telas como o terminal consegue
  desenhá-las, numa grade de caracteres. É a referência de `opcode` e foi
  gerada a partir da própria interface (`internal/ui`), então mostra o estado
  atual dela.

Ao mudar uma tela, atualize o protótipo correspondente junto.
